# Which Tool Do I Need?

Molecule offers two AI tools. Pick by what you want to do:

| I want to…                                                                        | Use                                         | Runs                   | Setup                                                    |
| --------------------------------------------------------------------------------- | ------------------------------------------- | ---------------------- | -------------------------------------------------------- |
| Chat about Molecule, DeSci and research projects in a ready-made assistant        | [MIRA](mira.md)                             | Web app                | None                                                     |
| Have my chat assistant read and add files in my Lab                               | [Agent Connect](agent-connect.md)           | In Claude, ChatGPT, Codex, Grok or Cursor | A browser sign-in: paste one address, then approve |

**Rule of thumb:** if you want to chat, use MIRA. If you want the chat app you already use to work in a Lab you own, use Agent Connect.

Building your own agent on the Labs API? Start at [Getting Started](../api-reference/getting-started/README.md), and ask us on the [Molecule Discord](https://t.co/L0VEiy4Bjk) if you get stuck.
